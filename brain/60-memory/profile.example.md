# Profile (example)

## Escopo
Fatos relativamente estáveis sobre o usuário, úteis para executar tarefas sem
perguntar de novo a cada interação.

## O que entra
- fuso horário e idioma de trabalho
- papel profissional e contexto de atuação
- ferramentas e canais usados no dia a dia

## O que não entra
- credenciais, documentos de identidade, dados sensíveis
- informação volátil (agenda do dia, status de tarefa)

## Exemplo neutro
- Fuso horário principal: UTC-3
- Idioma preferencial para respostas: pt-BR
- Canal principal de entrada: mensageria de texto
