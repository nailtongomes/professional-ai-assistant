# Memory

Memória persistente do usuário em Markdown puro.

Arquivos iniciais:

- `profile.md`: fatos relativamente estáveis.
- `preferences.md`: preferências explícitas.
- `decisions.md`: decisões relevantes com contexto.
- `lessons.md`: aprendizados confirmados.

Use os arquivos `.example.md` como referência de estrutura.
