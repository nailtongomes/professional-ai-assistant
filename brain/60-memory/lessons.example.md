# Lessons (example)

Aprendizados **confirmados** pelo uso. Um aprendizado só entra aqui quando houver
evidência; caso contrário, permanece como observação no Inbox.

## 2026-08-21 — Índices reduzem custo de leitura

Context:
Modelos consomem contexto demais quando não há ponto de entrada definido.

Lesson:
Índices curtos e navegáveis aceleram a seleção dos arquivos relevantes.

Evidence:
Fluxo `INDEX principal → índice de Skills → Skill selecionada` evita leitura
completa do brain.

## 2026-08-21 — Arquivos menores reduzem conflito de sincronização

Context:
`brain/` é sincronizado entre máquinas por Syncthing.

Lesson:
Notas menores e append controlado geram menos conflitos que arquivos monolíticos
reescritos com frequência.

Evidence:
Conflitos do Syncthing ocorrem por arquivo; menos reescrita, menos superfície.
