## 2026-08-21 — Índices reduzem custo de leitura

Context:
Modelos tendem a consumir contexto demais quando não há ponto de entrada.

Lesson:
Manter índices curtos e navegáveis acelera seleção de arquivos relevantes.

Evidence:
Fluxo recomendado: INDEX principal → índice de Skills → Skill selecionada.
