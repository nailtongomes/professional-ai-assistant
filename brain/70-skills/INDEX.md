# Skills Index

Use este índice para selecionar a Skill antes de executar qualquer ação.

Fluxo esperado:

```text
pedido do usuário
→ índice de Skills
→ seleção da Skill
→ leitura do SKILL.md
→ execução
```

## Formato de entrada

Cada Skill deve documentar:

- `name`
- `description`
- `path`
- `when-to-use`

Modelo:

```markdown
## <name>

Description:
...

Path:
<categoria>/<nome-da-skill>/SKILL.md

When to use:
...
```

Sem Skill adequada, ambígua ou insuficiente: não executar.
