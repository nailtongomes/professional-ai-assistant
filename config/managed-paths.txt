# Arquivos e diretórios GERENCIADOS pelo template.
#
# Só o que está listado aqui pode ser atualizado por scripts/sync.sh.
# Todo o resto do brain é USER DATA e nunca é tocado por um update —
# inbox, projetos, agenda, pessoas, memória, notas, backlogs e Skills locais.
#
# Paths são relativos à raiz do brain. Um path terminado em "/" é um
# diretório e vale recursivamente.
#
# Por que um manifesto em vez de separar 70-skills/ em managed/ e local/:
# a separação por diretório quebraria os índices e os paths já publicados nas
# Skills existentes, e obrigaria o usuário a decidir a categoria de cada Skill
# nova. O manifesto entrega a mesma garantia — "o que não está aqui não é
# tocado" — sem mexer na estrutura. Skills pessoais vivem lado a lado com as
# gerenciadas e ficam protegidas por omissão, que é o padrão seguro.
